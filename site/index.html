A file in, an argv out.

Hand-edit it, commit it, diff it. A wrong jump is visible before it runs, because the window shows the command it is about to hand to ssh.

What you write

~/.config/patchbay/patchbay.toml
[defaults]
user = "root"

[jack.bastion]
host = "bastion.example"
port = 2222

[jack.web]
host = "10.0.0.4"
user = "deploy"
jump = "bastion"

[jack.db]
host = "10.0.0.5"
jump = "web"
forward = ["5432:localhost:5432"]

What's in the window.

Every protocol opens as its own tab, never reimplemented - and the workflow around them is built in too.

Terminal

Your ssh on a real pty, not a client we wrote.

/usr/bin/ssh → xterm.js

Remote desktop

Decoded in-process onto a canvas.

IronRDP → <canvas>

Files

Browse, download, drag to upload.

/usr/bin/sftp + ControlMaster

Web UI

The device's own page, certificate explained.

child webview, never an iframe

Map view

Grouped by the route to a device, not the folder it's filed in.

a bastion down explains everything behind it

Marks & broadcast

Pick out a few devices, type once, reach every one of them.

⌘-click to mark → right-click to broadcast

Bulk actions

Mark two or more and a dock appears: move, delete, broadcast, once.

the same actions live in the right-click menu

An up, down or unreachable dot on every device, always current.

probed continuously, not on click

Session logs

An optional record of a session's output, kept beside the config.

logs/, off by default

A space is another config file. A team is one with a server behind it.

Your list is patchbay.toml. Every other space is one file in spaces/ beside it, same format. 

~/.config/patchbay/
├─ patchbay.toml          your own list
├─ team.toml              this machine's id and codes, never shared
├─ rdp_known_hosts        certificates seen, the way known_hosts works
└─ spaces/
   ├─ acme.toml           a team's list - this is the file that syncs
   └─ acme.toml.base      the last version both sides agreed on

Joining reads none of yours

A code creates a new file. Your own list is never read, never uploaded.

Merged per device, not per line

Two people adding two machines is not a conflict. Only the same field is.

Or point it at a file

Plain HTTP. Leave the code blank, give a raw git URL, get a read-only copy.

Nothing in a config is executed

The most a shared config can produce here is an ssh command line.
