Inherited by every device

Left empty, nothing is inherited and each device stands on its own. Anything set here applies to every device that doesn't override it - and your ~/.ssh/config still applies underneath either way.

One shared list

A team's device list is a file in a folder you already share. Put it on the team drive or a synced folder, point this at it, and everyone sees the same devices and folder notes. It holds no passwords, so sharing it shares hostnames and nothing more.

A path that isn't there yet is seeded with the devices and defaults you have now; a colleague points at the same path. Your own devices stay in this machine's file and come back when you clear it. Who can edit is whoever can write the file. A folder that syncs (OneDrive, Dropbox) works for a team that mostly reads; a team that edits at the same time wants a real share.
